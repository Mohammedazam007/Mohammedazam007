## 🚀 Featured Projects

### 🤖 JARVIS-X: Offline Voice AI Assistant
My B.Tech final-year project. A fully offline, voice-activated personal assistant that listens, understands, remembers, and answers without sending anything to the cloud. Privacy and low latency come built in because everything runs on the local machine.

**How it works:** a six-layer pipeline (user interaction → speech processing → retrieval and memory → knowledge processing → reasoning → response generation).

**Highlights**
- Wake-word detection and speech-to-text, so it responds hands-free
- Semantic search over personal knowledge using embeddings and a vector database
- Reads text from images with OCR and understands visual content
- Local LLM for reasoning, with spoken replies through offline text-to-speech
- Documented with a formal review report and architecture diagrams

**Stack:** Qwen3 · Faster-Whisper · BGE embeddings · ChromaDB · PaddleOCR · MobileCLIP · openWakeWord · Piper TTS

### 🚗 VistaLock: Vehicle Access Management
A number plate based access control system for campuses and apartments. Most ANPR projects stop at reading a plate, but VistaLock manages who is allowed in, where, and when, and keeps a full history.

**Highlights**
- Detects and reads number plates for vehicle identification
- Logs every vehicle with its plate number, date, entry time, and exit time
- Works across multiple sites and gates (campuses, apartments, and more)
- Access categories and visit status tracking, with an audit log of every access event
- PostgreSQL database running in Docker for easy setup

**Stack:** Python · PostgreSQL · Docker · Computer Vision

### 🎮 Hand Gesture Controlled Online Game
An online game controlled entirely with your hands, with no keyboard or mouse. The webcam tracks your hand in real time and converts gestures into in-game actions.

**Highlights**
- Real-time hand tracking through the webcam
- Gesture-to-action mapping for game controls
- Playable online

**Stack:** Python · Computer Vision

### 📣 IssuePulse: University Complaint Management System
A full-stack platform that replaces messy complaint handling on campus. Students raise issues, and staff track them through to resolution, so nothing gets lost.

**Highlights**
- Secure login and sessions using JWT authentication
- Students submit complaints and follow their status
- Staff and admins manage and resolve issues from a dashboard
- React frontend, Spring Boot REST API, MySQL database
- Containerized with Docker

**Stack:** Spring Boot · React · MySQL · JWT · Docker

### 🔗 Distributed URL Shortener
A backend and systems project that turns long URLs into short links and keeps working when traffic grows. It focuses on scalability and fast redirects.

**Highlights**
- Generates short, unique links for any URL
- Designed to run across multiple instances
- Cache layer for fast redirects on popular links

**Stack:** Java · Spring Boot · Redis
